# NeferWL documentation

NeferWL is a small Wayland compositor in Go. Start with Configuration to set up your keyboard, outputs and workflows, then use the guides below for desktop integration, architecture and troubleshooting.

- [Configuration](config.md): keys, actions, default bindings, layouts and HDR.
- [Architecture](architecture.md): owner goroutines, GC strategy and reusable purego libraries.
- [Desktop integration](desktop.md): sessions, clipboard, input methods, X11 apps and scripting.
- [Session locking](session-lock.md): external lockers, recovery and security limits.
- [Screen capture](capture.md): protocols, indicator, executable allowlist and portals.
- [Headless mode](headless.md): screenshots, scripted input and testing without a screen.
- [Performance](performance.md): VRR, real-time priority, profiling and frame stats.
