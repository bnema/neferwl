# NeferWL documentation

NeferWL is a small Wayland compositor in Go. Start with Configuration to set up your keyboard, outputs and workflows, then use the guides below for desktop integration, screen capture, performance and headless use.

- [Configuration](config.md): keys, actions, default bindings, layouts and HDR.
- [Desktop integration](desktop.md): sessions, clipboard, input methods, X11 apps, session locking and scripting.
- [Screen capture](capture.md): protocols, indicator, executable allowlist and portals.
- [Performance](performance.md): resource use, VRR and real-time priority.
- [Headless and server mode](server.md): run NeferWL without a screen, as a long-running server or a game streaming host with Sunshine.
- [Scripting and agents](control.md): sessions, actions, input, state and screenshots for scripts, tests and AI agents.

Developer documentation: [docs/dev](dev/index.md)
