# Repository rules

- Use Go 1.27 only; normal builds and tests use CGO_ENABLED=0.
- Keep a lightweight hexagonal architecture: core imports only stdlib and ports.
- Owner goroutines own window state; no mutex on window state.
- Use zerowrap logging with a `component` field on every entry.
- Run tests with `-race`.
- Use signed conventional commits: `type(scope): description`.

## Mocks (hard rule)

Test doubles are always generated by Mockery v3 (`testify` template). Never handwrite them.

- **No handwritten fakes, stubs or spies.** This includes structs implementing an interface in a test and function fields swapped by tests (`x.ioctl = func...`). `make check` runs `fakes-check`, which rejects `type fake…`/`stub…`/`spy…`/`mock…` in tests.
- **Every seam is an interface.** When a test needs to replace a dependency, add an interface and generate its mock:
  - Cross-layer dependencies go in `internal/ports`. Mocks: `internal/mocks/ports`, package `portsmocks`, type `MockX`.
  - Adapter-internal seams (e.g. a kernel ioctl) stay unexported in the adapter. Mocks: `<name>_mock_test.go` in the same package.
- **Add a `.mockery.yml` entry** for each new interface, run `make mocks` and commit the generated files. `make mocks-check` (CI) fails if they are stale or missing.
- Use mocks through `.EXPECT()`. Record calls with `RunAndReturn` when a test inspects arguments.
- Channel ports (sealed message interfaces in `ports/messages.go`) are tested by sending messages, not with mocks.
- Real protocol clients in wayland tests (`wlturbo` proxies) are test clients, not doubles.

## Checks before merge

`make check`, `make race`, `make mocks-check` and `staticcheck ./...` must pass.
